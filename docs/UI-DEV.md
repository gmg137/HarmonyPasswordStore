# 应用各个界面功能及样式优化

## 1. 初始设置页面
    - 首次进入应用时，用户需要进行初始设置；
    - 优化初始设置第二步"初始化密码仓库"-“新建仓库”-“导入GPG密钥”页面:
        - 优化导入GPG密钥的用户体验，增加导入成功或失败的提示信息；
        - 将原来粘贴GPG密钥的方式改为选择文件上传的方式，支持asc格式密钥文件上传；
        - 导入按钮位于原来的粘贴框的位置；
        - 原来的导入方式说明也应做相应修改；
    - 修复初始设置第二步"初始化密码仓库"-“克隆远程”的问题：
        - 输入https开头的地址时会提示“TLS加密通道初始化失败，HTTPS克隆暂不可用。请改用SSH地址”。
        - 输入git@开头的地址时会提示“SSH 克隆暂不可用，请检查SSH密钥是否已配置”，在配置ssh密钥后还是会有相同的错误提示。
        - 在克隆远程仓库选项中，增加SSH密钥配置入口，提示用户如何配置SSH密钥，并在配置成功后允许克隆远程仓库。
